## 🎯 Project Overview

This is a **complete, production-grade e-commerce analytics project** that mirrors real-world business intelligence workflows used at top companies. It tracks the full customer journey — from first browsing to final purchase — across 10,000 sessions in October 2025.

| Dimension | Detail |
|---|---|
| **Dataset** | 10,000 user sessions |
| **Period** | October 1–31, 2025 |
| **Funnel Stages** | Browse → Add to Cart → Checkout → Purchase |
| **Tools Used** | Power BI, DAX, Python, Excel, CSV |
| **Business Goal** | Identify drop-off points & maximize revenue |

## 💡 Business Recommendations

### 🔥 Priority 1 — Fix Checkout Drop-off (2,444 users lost)

The checkout stage has a **69.4% drop-off rate** — the single biggest revenue leak.

| Action | Expected Impact |
|---|---|
| Reduce form fields from 10+ to 5–6 | Reduces friction |
| Add guest checkout option | Captures non-registered users |
| Show step progress indicator (Step 1 of 3) | Reduces abandonment anxiety |
| Add trust badges (SSL, money-back guarantee) | Increases confidence |
| Offer UPI, wallets, and card payments | Reduces payment failure |

**📈 Expected Lift: +15–25% checkout conversion**

---

### 🔥 Priority 2 — Optimize Mobile Experience

Mobile is 0.3% behind Desktop. With mobile traffic growing globally, even small UX wins = significant revenue.

| Action | Expected Impact |
|---|---|
| One-click / express checkout | Reduces steps |
| Page load <2 seconds | Reduces bounce |
| Touch-optimized navigation | Reduces UX friction |
| Mobile-specific A/B tests | Data-driven improvements |

**📈 Expected Lift: +10–20% mobile conversion**

---

### 🔥 Priority 3 — Reallocate Marketing Budget

Email (10.2%) and Social Media (10.8%) underperform Organic (11.2%).

| Action | Expected Impact |
|---|---|
| Increase budget towards Organic & Google Ads | Capture high-intent users |
| A/B test email subject lines + CTAs | Improve email open & click rates |
| Retarget cart abandoners via Social | Recover warm leads |

**📈 Expected Lift: +5–15% ROI**

## 🔢 DAX Formulas

Key measures used in the Power BI dashboard:

```dax
-- Conversion Rate
Conversion Rate = DIVIDE([Total Purchases], [Total Sessions], 0)

-- Average Order Value
Avg Order Value = DIVIDE([Total Revenue], [Total Orders], 0)

-- Stage Drop-off Rate
Cart Dropoff Rate = 
    DIVIDE(
        [Browse Users] - [Cart Users],
        [Browse Users],
        0
    )

-- Revenue by Category (DAX)
Revenue by Category = 
    CALCULATE(
        SUM(Sales[OrderValue]),
        ALLEXCEPT(Sales, Sales[Product_Category])
    )
```
